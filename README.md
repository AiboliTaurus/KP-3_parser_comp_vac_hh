# Парсер вакансий с hh.ru

## Описание проекта
Проект для получения данных о компаниях и вакансиях с сайта hh.ru, их сохранения в базу данных PostgreSQL и предоставления интерфейса для анализа этих данных.

## Функциональность
- Получение данных о компаниях через API hh.ru
- Получение вакансий компаний
- Сохранение данных в PostgreSQL
- Анализ данных через удобный интерфейс
- Валидация всех данных перед сохранением
- Поддержка переменных окружения через .env
- Полное тестирование с покрытием >90%

## Быстрый старт
1. Клонировать репозиторий
2. Создать виртуальное окружение
3. Установить зависимости: `pip install -r requirements.txt`
4. Скопировать `.env.example` в `.env` и настроить подключение к БД
5. Запустить: `python main.py`
