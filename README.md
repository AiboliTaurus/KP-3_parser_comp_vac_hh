# Парсер вакансий с HeadHunter (hh.ru)
Проект для поиска, фильтрации и сохранения вакансий с сайта HeadHunter (hh.ru) через публичное API.
## Возможности
- 🔍 Поиск вакансий по ключевым словам
- 💰 Фильтрация по зарплате
- 🏢 Фильтрация по компаниям
- 📊 Сортировка по зарплате (по убыванию)
- 💾 Сохранение результатов в различные форматы (JSON, CSV, TXT)
- 📈 Просмотр сохраненных вакансий
- 🎯 Фильтрация сохраненных вакансий по различным критериям
## Установка и запуск
### Предварительные требования
- Python 3.11 или выше
- Poetry (менеджер зависимостей)
### Установка
1. Клонируйте репозиторий:
```
git clone <ваш-репозиторий>
cd hm_feacture_4_hh_vacancies
```
2. Установите зависимости:
```commandline
pip install -r requirements.txt
```

### Запуск программы
Запустите основной файл программы:
```commandline
python main.py
```
## Использование
### Основные команды в меню
#### Поиск вакансий
- Введите поисковый запрос (например: "Python разработчик")
- Укажите количество вакансий для вывода
- Задайте ключевые слова для фильтрации (опционально)
- Укажите диапазон зарплат (опционально, формат: "50000-150000")
- Сохраните результаты в файл (опционально)
#### Показать сохраненные вакансии
- Просмотр всех сохраненных вакансий
- Укажите количество для отображения (или "all" для всех)
#### Фильтровать сохраненные вакансии
- По ключевому слову
- По минимальной зарплате
- По компании
- Комбинированные фильтры 
#### Очистить сохраненные вакансии
- Полная очистка файла с сохраненными вакансиями

### Форматы сохранения
#### Проект поддерживает три формата сохранения:
- JSON (data/vacancies.json) - основной формат с полной информацией
- CSV (data/vacancies.csv) - для работы с табличными редакторами
- TXT (data/vacancies.txt) - для удобного чтения

### Проект использует следующие инструменты для поддержания качества кода:

2) **Flake8** - проверка стиля кода
3) **isort** - сортировка импортов
4) **mypy** - проверка типов
